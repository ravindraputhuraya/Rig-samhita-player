## 📖 About

The **Rig Samhita Player** is a purpose-built study environment designed to support students engaged in the sincere, structured, and guided study of the Rig Veda under the direction of a Guru.

This tool is **not a replacement for a Guru**; it is a digital extension of the traditional **Guru-Śiṣya Paramparā**, created to assist in structured revision and mindful repetition.

> 🙏 **Important:** This player is for revision and reflection only. Proper pronunciation and chanting techniques must be learned from a qualified Guru.

---

## ✨ Key Features

### 🎯 Core Functionality
- **🌐 Online Player**: Stream directly from your browser - no downloads needed!
- **💾 Offline Player**: Download and use without internet connection
- **🎵 Audio-Text Synchronization**: Real-time alignment of audio with Vedic text in Devanagari and Kannada scripts
- **🔄 Precision Looping**: 
  - Vakya (mantra) looping
  - Sukta repetition
  - Custom Rig range selection for focused practice
- **📚 Bi-lingual Meanings**: 
  - Pada-by-pada (word-by-word) meanings
  - Full phrase meanings in Kannada and English
  - Deep insights and contextual explanations

### 📝 Study Tools
- **✍️ Integrated Notes**: Personal study journal to record:
  - Guru's profound insights
  - Pronunciation reminders
  - Personal reflections
  - Export notes as JSON for backup
- **🔍 Variable Zoom**: Adjust text size from 100% to 300% for comfortable reading
- **⚡ Playback Speed Control**: 0.75x to 1.5x speed adjustment
- **🎚️ Volume Control**: Fine-tune audio levels

### 🔒 Privacy & Security
- **Privacy-First**: All data stays in your browser
- **Offline Capable**: Works without internet (offline version)
- **No Server Storage**: Your notes and preferences remain private

## 🚀 How to Use

### Option 1: Online Player (Recommended for Beginners)
1. 🌐 Visit **[Online Player](https://ravindraputhuraya.github.io/Rigveda-samhita-player/)**
2. ✅ Accept the disclaimer
3. 📂 Select **Mandala** from dropdown (1-10)
4. 📖 Select **Sukta** number
5. ▶️ Press Play and start learning!

### Option 2: Offline Player (For Offline Use)
1. **Download Resources:**
   - Download `RSP_V4_A_P.html` (main player)
   - Download `jszip.min.js` (required library)
   - Download your desired Mandala ZIP file(s)

2. **Setup:**
   - Place all downloaded files in the same folder
   - Keep the ZIP files unextracted

3. **Launch:**
   - Open `RSP_V4_A_P.html` in your browser
   - Click "Open ZIP" button
   - Select the Mandala ZIP file you want to study

4. **Study:**
   - Use navigation arrows to move between Suktas
   - Click on mantra numbers to jump to specific Rigs
   - Access meanings by clicking the **ॐ** button
   - Adjust settings using the **⚙** button

## 🎓 Learning Path

### For Beginners (Śravaṇa - Listening Phase)
1. Start with Mandala 1, Sukta 1
2. Use **0.75x speed** for careful listening
3. Enable both Kannada and English meanings
4. Take notes on pronunciation patterns

### For Intermediate Students (Paṭhana - Recitation Phase)
1. Use **Sukta Loop** mode for repetition
2. Practice with normal speed (1.0x)
3. Focus on Pada-by-Pada meanings
4. Record Guru's corrections in notes

### For Advanced Students (Svādhyāya - Self-Study)
1. Use **Custom Rig Loop** for specific verses
2. Practice at **1.25x-1.5x** for fluency
3. Add personal insights to notes
4. Export notes for long-term reference
